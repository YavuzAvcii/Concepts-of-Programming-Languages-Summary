▸ Pioneer Era (1943–1952)
1943–1945 Plankalkül Konrad Zuse (Germany) Scientific First real language design. Never implemented; published 1972. Three-row notation (statement / subscripts / types). Arrays & Records Iteration (no goto) Assertions 
| Assign A[4]+1 to A[5]
| (three-row notation)
  | A + 1 => A
V | 4       5
S | 1.n     1.n

V = subscript row
S = type row (1.n = n-bit int)
1949 Short Code John Mauchly (BINAC/UNIVAC I) Scientific First "pseudocode." Byte-pair coded math expressions. Pure interpreter — ~50× slower than machine code. Pure interpretation 
; X0 = SQRT(ABS(Y0))
; encoded as byte-pairs:
00 X0 03 20 06 Y0

03 = =    06 = abs value
20 = sqrt  X0,Y0 = variables
1951–1953 Speedcoding John Backus (IBM 701) Scientific Virtual floating-point calculator on IBM 701. Included sin, arctan, log, sqrt. Programs taking 2 weeks in machine code done in hours. Auto-increment address registers 
; Pseudoinstruction set example
; (conceptual — no standard syntax)
LOAD  R1, X
SQRT  R1         ; sqrt(X)
STORE R1, RESULT
; ~700 words usable memory
; add took 4.2 ms
1951–1953 A-0 / A-2 Grace Hopper (UNIVAC) Scientific First "compiling" systems — expanded pseudocode into machine-code subprograms, like macros. Macro expansion 
; A-0 pseudocode (conceptual)
; short numeric codes triggered
; machine-code subprograms

23 17 04  ; call subprogram 23
                  ; with args 17, 04
▸ First Compiled High-Level Languages (1954–1960)
1954–1957 Fortran I/II John Backus et al. (IBM 704) Scientific First widely accepted compiled language. All types fixed at compile time; no recursion. DO loop IF statement Implicit typing (I–N = integer) Fortran II: independent subroutine compilation

  Sum = Sum + Int_List(Counter)

1958–1960 Lisp John McCarthy, MIT AI Project AI / Functional First functional language. Code and data share the same form (parenthesized lists). Atoms & Lists Recursion Garbage collection Conditional expressions 
; Check if two lists are equal
(DEFUN equal_lists (lis1 lis2)
  (COND
    ((ATOM lis1) (EQ lis1 lis2))
    ((ATOM lis2) NIL)
    ((equal_lists
       (CAR lis1) (CAR lis2))
     (equal_lists
       (CDR lis1) (CDR lis2)))
    (T NIL)))
mid-1970s Scheme MIT Functional Small, clean Lisp dialect. Static scoping only. First-class functions. Lexical scoping Functions as first-class values 
; Recursive factorial
(define (factorial n)
  (if (= n 0)
      1
      (* n (factorial (- n 1)))))

(factorial 5)  ; => 120
1958–1960 ALGOL 60 Joint ACM (USA) + GAMM (Europe) Scientific First internationally designed & formally described (BNF) language. Never widely adopted in USA (no I/O, IBM backed Fortran). Block structure & scoping Pass-by-value & pass-by-name Recursive procedures Stack-dynamic arrays

1959–1960 COBOL Short Range Committee / DoD (based on FLOW-MATIC by Grace Hopper) Business First major business language. DoD-mandated. ~800M lines still active (late 1990s). Hierarchical records (first) Long identifiers (30 chars) English-like syntax Separate DATA / PROCEDURE divisions

  STOP RUN.

1963–1964 Basic John Kemeny & Thomas Kurtz (Dartmouth) Education First widely used timesharing language. First program ran 4:00 a.m., May 1, 1964. Resurgent via Visual Basic (1991). Terminal-based access Beginners friendly 14 statement types

INPUT listlen

▸ Ambitious Designs & Data Abstraction (1963–1973)
1963–1966 PL/I IBM + SHARE (3×3 Committee) ScientificBusinessSystems First universal language — meant to replace Fortran, COBOL, Lisp, and assembly. Criticized by Dijkstra for "baroqueness." Concurrency (first) Exception handling (23 types, first) Pointers as data type (first) Array cross-sections 
PLIEX: PROCEDURE OPTIONS(MAIN);
  DECLARE INTLIST(1:99) FIXED;
  DECLARE (SUM, AVG) FIXED;
  SUM = 0;
  GET LIST(LISTLEN);
  DO I = 1 TO LISTLEN;
    GET LIST(INTLIST(I));
    SUM = SUM + INTLIST(I);

  PUT LIST('Average:', AVG);

1962–1967 SIMULA 67 Nygaard & Dahl (Norway) OOP Pioneer Extended ALGOL 60. Introduced the class to support coroutines for simulation. Foundation of data abstraction and OOP. Class construct (first) Data abstraction Coroutines 
Class Vehicle(speed, fuel);
  Integer speed; Real fuel;
Begin
  Procedure Move;
  Begin
    fuel := fuel - 0.1 * speed
  End;
End Vehicle;

Ref(Vehicle) v;
v :- New Vehicle(60, 50.0);
v.Move;
1968–1969 ALGOL 68 van Wijngaarden et al. Scientific Based on orthogonality — few primitive types + unrestricted combining rules. Described using van Wijngaarden grammars (too complex for wide adoption). User-defined data types (first) Flex arrays (implicit heap-dynamic)

early 1970s Prolog Colmerauer & Roussel (Aix-Marseille); Kowalski (Edinburgh) Logic Programming Based on Logic. Uses predicate calculus + resolution. First interpreter 1972, Marseille. Facts & Rules Goal-based queries Non-procedural 
% Facts
mother(joanne, jake).
father(vern, joanne).

% Rule
grandparent(X, Z) :-
    parent(X, Y),
    parent(Y, Z).

% Query
?- father(vern, joanne).
% => true
?- grandparent(vern, jake).
% => true

1972 C Dennis Ritchie (Bell Labs) Systems Built for UNIX. Influenced by ALGOL 68 (for, switch, assignment operators, pointers). Standardized C89, then C99. Rich operator set Minimal type checking (flexible/unsafe) Pointers 
int main() {
  int intlist[99], sum=0,
      average, result=0;
  scanf("%d", &listlen);
  for (i=0; i<listlen; i++) {
    scanf("%d", &intlist[i]);
    sum += intlist[i];
  }
  average = sum / listlen;
  for (i=0; i<listlen; i++)
    if (intlist[i] > average)
      result++;
  printf("%d\n", result);
}
1974–1983 Ada 83 Jean Ichbiah / Cii Honeywell-Bull (DoD) Embedded / DoD History's largest language design effort. Named after Augusta Ada Byron (1815–1851), world's first programmer. Packages (data abstraction) Exception handling Generic units Tasks + Rendezvous (concurrency) 
procedure Ada_Ex is
  type Int_List_Type is
    array (1..99) of Integer;
  Int_List : Int_List_Type;
  Sum, Average : Integer;
begin
  Sum := 0;
  for I in 1..List_Len loop
    Get(Int_List(I));
    Sum := Sum + Int_List(I);

  Average := Sum / List_Len;

▸ Object-Oriented Languages (1972–2002)
1972–1980 Smalltalk-80 Alan Kay et al. (Xerox PARC) Object-Oriented First language to fully support OOP. Pioneered windowing / GUI systems. Everything is an object; all operations are message sends. Pure OOP Message passing Classes & inheritance

1980–1985 C++ Bjarne Stroustrup (Bell Labs) Object-OrientedSystems C + OOP features from SIMULA 67. Evolved: C with Classes → C++ → R2.0 → R3.0. Inherited C's insecurities. Classes & inheritance Virtual methods Operator overloading Templates Multiple inheritance

public:
  virtual void speak() {
    cout << "...";
  }
};
class Dog : public Animal {

1990–1995 Java James Gosling et al. (Sun Microsystems) Object-OrientedWeb Started for embedded consumer electronics; pivoted to Web (applets) 1993. Simpler, safer C++; OOP-only. Garbage collection No pointers Array index checking Single inheritance + interfaces JVM + JIT 
class Example {
  public static void main(
      String[] args) {
    int[] list = new int[99];
    int sum = 0, avg, result = 0;
    for (int x : list) sum += x;
    avg = sum / list.length;
    for (int x : list)
      if (x > avg) result++;
    System.out.println(result);
  }
}
