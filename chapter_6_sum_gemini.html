Chapter 6: Data Types

A data type defines a collection of data values and a set of predefined operations on those values[cite: 30]. The contemporary concepts of data typing have evolved to provide flexible structures and abstract data types[cite: 33, 44].

1. Primitive Data Types

These are data types not defined in terms of other types[cite: 78].

  • Numeric: Integers are usually supported directly by hardware and use two's complement for negative numbers[cite: 87, 100]. Floating-point types model real numbers using fractions and exponents, usually following the IEEE 754 standard[cite: 106, 114, 116].
  • Decimal: Store a fixed number of decimal digits, which is essential for business data processing (e.g., COBOL)[cite: 149, 150].
  • Boolean: Represent true or false, often stored in a single byte for efficient access[cite: 163, 171].
  • Character: Stored as numeric codes like ASCII (8-bit) or Unicode (16-bit or 32-bit)[cite: 174, 177, 183].

Quiz Focus: Float vs. Decimal

Question to expect: What are the advantages and disadvantages of decimal types compared to floating-point types?

  • Advantage: Decimal types can exactly represent decimal values, avoiding the loss of precision that occurs in floating-point representations[cite: 152, 153].
  • Disadvantage: Decimal types have a restricted range because they do not use exponents, and their representation in memory is wasteful[cite: 154, 157].

2. Character String Types

Values consist of sequences of characters[cite: 187]. They can be treated as arrays of characters (like in C/C++) or as primitive types (like in Python)[cite: 204, 231].

Quiz Focus: String Length Bindings

Question to expect: Describe the three string length options.

  • Static length: Set when created and immutable (e.g., Java's String class, Python)[cite: 266, 267].
  • Limited dynamic length: Can vary up to a declared maximum length (e.g., C-style strings using a null terminator)[cite: 268, 270].
  • Dynamic length: Can vary with no maximum, offering flexibility but requiring overhead for dynamic memory allocation (e.g., JavaScript, Perl)[cite: 271, 272].

3. Enumeration & Subrange Types

An enumeration type defines all possible values as named constants[cite: 326].

Quiz Focus: Enumeration Safety

Question to expect: How do C# or Java enumeration types improve reliability compared to C/C++?

  • In C#, enumerations are not coerced to integers, restricting operations to those that make sense (e.g., you cannot do arithmetic on them)[cite: 377, 378].
  • They restrict values to the defined range, preventing assignment of invalid values[cite: 379, 399].
  • C and C++ treat them as integers (or coerce them), which defeats type checking and allows meaningless operations[cite: 356, 402].

4. Array Types

An array is a homogeneous aggregate of data elements where individuals are identified by their position (indices)[cite: 410].

  • Rectangular arrays: All rows have the same number of elements[cite: 601].
  • Jagged arrays: Arrays of arrays, where row lengths can differ[cite: 603, 606].
  • Slices: Mechanisms for referencing a substructure of an array as a unit[cite: 617, 620].

Quiz Focus: Array Subscript Binding Categories

Question to expect: Define the four categories of arrays based on subscript bindings and storage allocation.

  • Static: Subscript ranges and storage are fixed before run time. Efficient but inflexible[cite: 480, 481, 482].
  • Fixed stack-dynamic: Subscript ranges are statically bound, but allocation happens at declaration elaboration during run time (space efficient)[cite: 483, 484].
  • Fixed heap-dynamic: Subscript ranges and storage are bound upon user request from the heap, then remain fixed[cite: 488, 489].
  • Heap-dynamic: Binding of ranges and storage can change any number of times during execution (most flexible, least efficient)[cite: 492, 493, 494].

Quiz Focus: Array Implementation

Question to expect: Define row major order and column major order.

  • In row major order, elements of the first row are stored contiguously, followed by the second row, etc.[cite: 684, 685].
  • Array access requires an access function that computes memory addresses using multiplication and addition[cite: 657, 709].

5. Associative Arrays, Records, and Tuples

  • Associative Arrays: An unordered collection of elements indexed by keys (e.g., hashes in Perl or dictionaries in Python)[cite: 743, 752, 776]. Ideal for paired data and fast lookups[cite: 786, 787].
  • Records: A heterogeneous aggregate where elements (fields) are identified by names and accessed via offsets[cite: 799, 879].
  • Tuples: Similar to records but elements are not named[cite: 896]. Often used in Python and functional languages to return multiple values from functions[cite: 928].

6. Union Types

A union stores different type values at different times in the same memory location[cite: 1020].

Quiz Focus: Free vs. Discriminated Unions

Question to expect: What is the difference between a free union and a discriminated union?

  • Free unions (used in C/C++) do not include a type indicator and bypass type checking, making them highly unsafe[cite: 1032, 1034].
  • Discriminated unions (used in F#, ML) require a type indicator (tag or discriminant) for type checking, ensuring safety[cite: 1046, 1047].

7. Pointers and Reference Types

Pointers store memory addresses and are used for indirect addressing and dynamic heap management[cite: 1093, 1095, 1096]. Reference types refer to an object rather than an address, restricting dangerous arithmetic operations (used heavily in Java/C#)[cite: 1245, 1246, 1264].

Quiz Focus: Pointer Problems

Question to expect: What are the two common problems with pointers?

  • Dangling pointers: A pointer that contains the address of a heap-dynamic variable that has already been deallocated[cite: 1158].
  • Lost heap-dynamic variables (Memory Leaks): A dynamic variable that is no longer accessible because all pointers to it have been reassigned or destroyed[cite: 1188, 1193].

Follow-up: What are the solutions to dangling pointers?

  • Tombstones: An extra cell that acts as an intermediary; it is set to nil upon deallocation[cite: 1303, 1305].
  • Locks-and-keys: Pointers must carry a key that matches a lock value on the dynamic variable; deallocation changes the lock, invalidating old keys[cite: 1311, 1313, 1319].

Quiz Focus: Garbage Collection

Question to expect: Describe the eager and lazy approaches to heap storage recovery.

  • Reference Counters (Eager/Incremental): Every cell maintains a counter of pointers pointing to it. When the count drops to zero, the cell is reclaimed immediately. It struggles with circular references and adds execution overhead[cite: 1347, 1349, 1357].
  • Mark-Sweep (Lazy): Collects garbage only when memory runs out. It traces all active pointers, marks reachable cells, and sweeps away unmarked cells into the available space list. It causes execution delays when running[cite: 1362, 1363, 1369, 1370].

8. Type Checking, Strong Typing, and Equivalence

Type checking ensures operands are of compatible types[cite: 1474]. Automatic conversion of types is called coercion[cite: 1476].

Quiz Focus: Strong Typing

Question to expect: Define a strongly typed language and explain why C/C++ are not strongly typed.

  • A programming language is strongly typed if type errors are always detected[cite: 1494].
  • C and C++ are not strongly typed because they include free union types, which allow values to bypass type checking[cite: 1498].
  • Note: Coercion weakens the value of strong typing by hiding logical errors that are converted automatically rather than flagged[cite: 1507, 1511].

Quiz Focus: Type Equivalence

Question to expect: What is the difference between name type equivalence and structure type equivalence?

  • Name type equivalence: Variables have equivalent types if they are defined in the same declaration or use the exact same type name. It is highly restrictive but easy to implement[cite: 1531, 1535].
  • Structure type equivalence: Variables have equivalent types if their internal structures are identical. It is flexible but difficult to implement and risks confusing conceptually different types that happen to share a structure[cite: 1532, 1548, 1555].
